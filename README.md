# Ductus

Handwritten notebooks for pen and touch, on Linux, Windows and Android.

## Features

- Notebooks with sections and pages, on endless or paper pages (blank, lined, grid, dotted)
- Pen, highlighter, eraser, lasso, shapes, text boxes, pictures and formulas (LaTeX or Typst)
- Write on PDFs directly or import them as note pages
- Search through typed text, PDFs and handwriting
- Handwriting to text or formulas, on the device
- Earlier versions and a trash for every page
- Export and print as PDF, one page or a whole notebook

## Install

Download the file for your system from [Releases](https://github.com/wieluk/ductus/releases):

- **Linux:** `flatpak install --user Ductus-<version>-linux-x86_64.flatpak`
- **Windows:** run `Ductus-<version>-windows-x64-setup.exe`
- **Android:** open `Ductus-<version>-android-arm64.apk` and allow the install

Ductus tells you when a new version is out.

## Your notes

Notes are plain files in a folder of your choice (Documents/Ductus by default): pages are SVG
files, PDFs stay PDFs. Sync that folder with Nextcloud, Syncthing or similar to use your notes
on several devices. Earlier versions and the trash stay on each device.
